# Improvement 41: Fix Search Result Issues

## Problems

### 1. Back to Home button triggers unwanted List of Date reload
When user clicks "Back to Home" button from search results, the app opens the Home page but then automatically reloads the "List of Date", which is not the intended behavior. The Home page should remain as the Home page without triggering any date list operations.

### 2. Footer is not visible in Search Results
The footer area is not visible when viewing search results, making it impossible to see any footer messages or status information while searching.

### 3. Vertical scroll is visible when search results are few
When there are only a few search results that don't require scrolling, the vertical scrollbar is still visible, creating unnecessary UI clutter.

### 4. Search result area is too narrow and doesn't expand properly
The search result area is narrow and doesn't utilize the full available space:
- When the right column is closed, search results should expand to the right side of the app
- When the right column is opened, search results should expand to the right side of the right column
Currently, the search results area doesn't respond to the right column state changes.

### 5. Right column not visible when clicking Advanced Search or Clear search
When user clicks "Advanced Search" from Home or "Clear search" from search results, the right column becomes not visible, making it impossible to search again. The search tools should remain accessible.

### 6. Use PhotosList.jsx directly for search results instead of SearchPage.jsx
Instead of having a separate SearchPage.jsx component, simply use PhotosList.jsx for search results. The main difference should be just which tabs are enabled/disabled depending on the mode (search result mode vs date list mode). This would eliminate layout inconsistencies and ensure consistent behavior.
