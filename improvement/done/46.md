# 手動検索実行への変更（自動再検索廃止）

## 概要

improvement #44で設計されたが未実装だった手動検索実行機能を実装し、フィルター変更時の自動再検索を廃止してより明確なユーザー操作フローを実現する。

## 🎯 緊急度：中（UX改善）

### 現状の問題

**UX問題**:
- `src/App/PhotosList.jsx:139-153` - フィルター変更時の自動再検索が有効
- improvement #44設計書では手動実行のみに変更予定だったが未実装
- ユーザーが意図しない検索実行が発生
- フィルター調整中に何度も検索が実行されるパフォーマンス問題

**設計方針**:
フィルター変更は状態更新のみ行い、「Apply Filters」ボタン押下時のみ検索実行する。

## 実装対象ファイル

- `src/App/PhotosList.jsx:handleFiltersChange` - 自動検索実行の削除
- `src/components/SearchTools.jsx` - 手動実行ボタンの強調
- `src/style.css` - 手動検索ボタンのスタイル追加

```javascript
            </p>
        </div>

// hasActiveFilters 判定ロジック追加
const hasActiveFilters = Object.keys(filters).some(key => {
    const value = filters[key];
    if (typeof value === 'boolean') return value;
    if (typeof value === 'number') return value > 0;
    if (typeof value === 'string') return value.length > 0;
    if (typeof value === 'object' && value !== null) {
        return Object.values(value).some(v => v && v.toString().length > 0);
    }
    return false;
});
```

## UX改善効果

- **操作明確化**: ユーザーが意図的に検索を実行するフローに変更
- **パフォーマンス向上**: フィルター調整中の不要な検索実行を削除
- **UI向上**: より明確な検索実行ボタンと説明テキスト
- **予期しない挙動削除**: フィルター変更時の自動検索による混乱を解決

## 決定事項

- **検索実行**: 手動実行のみ（自動再検索完全廃止）
- **ボタン配置**: Advanced Filters下部に専用セクション
- **ボタン状態**: クエリまたはフィルターがある場合のみ有効
- **UI表示**: 明確なラベルと操作ヒント表示
- **既存互換性**: 既存の検索機能は影響なし
