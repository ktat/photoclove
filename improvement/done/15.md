# when .photoclove-uuid creation is forbidden

親ディレクトリのPermissionによって、
.photoclove-uuidを作成できない可能性があります。

その場合、代わりに、インポート元のファイル名のディレクトリ名を
sha256 hashにしたものをインポート先のディレクトリ名としてください。

また、後にpermissionの問題が解決する可能性も考えて、
インポート時に以下のチェックを行う必要が有ります。
疑似コードで書いています。なお、以下の疑似コードは細かいチェックロジック等は省いているので、
自分で補完してください。

```
if インポート先に sha256 hash と考えられる(長さ及び文字種をチェック)ディレクトリがある
   $a = true
else
   $a = false
end

if 親ディレクトリに .photoclove-uuid がある
   .photoclove-uuid にuuid(= $c とする)を使って
    import先を インポート先/yyyy-mm-dd/$c(= $dとする) とする
else
  親ディレクトリに.photoclove-uuidの作成を試みる
  if 作成成功
    .photoclove-uuid にuuid(= $c とする)を入れる
    $b = インポート元のファイルのフルパスのディレクトリ名の sha256 hash値
    if $a is true
      if $b のディレクトリ名が存在する
         $b 以下のファイルを、$c のディレクトリ以下に移動
         既存のDBのレコードの変更も行う
      end
    end
    import先を インポート先/yyyy-mm-dd/$c(= $dとする) とする
  else
    $b = インポート元のファイルのフルパスのディレクトリ名の sha256 hash値
    import先を インポート先/yyyy-mm-dd/$b(= $dとする) とする
  end
  $d にインポートを行う
  DBへのレコード追加を行う
end
```
