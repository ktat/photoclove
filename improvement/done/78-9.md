# Change Recent limit from fixed 60 to config.max_photos_per_fetch

## Task Description
Update the Recent photos mode to use the configurable `config.max_photos_per_fetch` setting instead of the hardcoded limit of 60.

## Implementation Details

### Current Implementation
In `useFetchConfig.js` (which will be deleted):
```javascript
const config = {
    fetch_method: "recent",
    value: "recent",
    title: "Recent Photos (60 most recent)",
    max_photos_per_fetch: 60  // Fixed value
};
```

### New Implementation
In `ViewMode.getUnifiedPhotoParams()`:
```javascript
case VIEW_MODES.RECENT:
    return { 
        ...baseParams, 
        search_type: "recent",
        limit: appConfig?.max_photos_per_fetch || 1000  // Use config setting
    };
```

### Title Update
In `ViewMode.getModeTitle()`:
```javascript
case VIEW_MODES.RECENT: 
    return 'Recent Photos';  // Remove hardcoded count from title
```

## Files to Modify
- `src/domain/ViewMode.js` - Update getUnifiedPhotoParams() for RECENT mode
- Any UI components showing "Recent Photos (60 most recent)" text

## Success Criteria
- [ ] Recent mode uses config.max_photos_per_fetch instead of fixed 60
- [ ] Recent photos title no longer shows hardcoded count
- [ ] Setting changes in config affect Recent photos display

## Benefits
- **User Control**: Users can configure how many recent photos to show
- **Consistency**: All modes use the same configurable limit system
- **Flexibility**: Easy to adjust based on performance needs
- **Standards**: Follows same pattern as other modes

- Verify default behavior when config is missing
- Ensure performance is acceptable with larger limits
- Test Recent mode displays correct number of photos
