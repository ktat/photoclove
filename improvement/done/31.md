# Improve Editor

Add cropping feature to Editor.

1. User click `Crop` button
2. `Done` and `Cancel` button appear when `Crop` button is clicked. This status is called Editting mode.
2. User can choose the area user want to crop with mouse while Editting mode.
3. User click `Done` and finish Editting mode and add CSS stlye
4. User click `Cancel` and quit Editting mode.
