# Fix `Saved Searches`

`Saved Searches` design is not good like this:

```
title     icon icon icon
query

Created:
yyyy/mm/dd Last
used: yyyy/mm/dd
```

Shoud be:

```
title     icon icon icon
Created: yyyy/mm/dd 
Last used: yyyy/mm/dd
▷ Search Condition
```

last line `▷  Search Conditio` is toggle
When open it, user can see search condition in table. 

````
| query | ...        |
| Star  | 4          |
| From  | yyyy/mm/dd |
| To    | yyyy/mm/dd |
````

It just an example. Please consider better UI.

## Implementation Plan

### How to implement the task:

The current `Saved Searches` UI shows the search query text prominently but displays creation and last used dates in a cramped format. The improved design will:

1. **Restructure the layout** to move dates to a single compact line
2. **Add a collapsible search condition panel** with a toggle arrow (▷)
3. **Display search conditions in a structured table format** when expanded
4. **Improve visual hierarchy** with better typography and spacing

### Which source code will be changed:

**Primary file to modify:**
- `src/components/SavedSearches.jsx` (lines 200-300 approximately) - Main component rendering individual saved search items

**Secondary files to modify:**
- `src/components/search.css` (lines 391-572) - Styling for saved searches UI
- Specifically the `.saved-search-item` class and related styles

### Detailed Implementation Steps:

1. **Update JSX structure** in `SavedSearches.jsx`:
   - Combine created/last used dates into single line with proper formatting
   - Add collapsible section with toggle arrow for search conditions
   - Create structured table layout for search parameters

2. **Add state management** for expanded/collapsed state:
   - Track which saved searches have expanded condition panels
   - Implement toggle functionality

3. **Create search condition display logic**:
   - Parse the saved search filters object
   - Format different filter types (dates, ranges, selections) appropriately
   - Handle empty/undefined filter values gracefully

4. **Update CSS styling**:
   - Adjust spacing and typography for the new layout
   - Style the toggle arrow with rotation animation
   - Create table styling for search conditions
   - Ensure responsive design works with new layout

5. **Improve information architecture**:
   - Show most important info (title, dates) at top level
   - Hide detailed search parameters behind toggle to reduce clutter
   - Use consistent date formatting throughout

### Key Features to Implement:

- **Compact date display**: "Created: yyyy/mm/dd • Last used: yyyy/mm/dd"
- **Toggle arrow**: ▷ (collapsed) / ▽ (expanded) with smooth rotation

### Additional Implementation Details:

#### State Management Approach:
```javascript
// Track expanded state per search item using Set
const [expandedSearches, setExpandedSearches] = useState(new Set());

const toggleExpanded = (searchId) => {
  const newExpanded = new Set(expandedSearches);
  if (newExpanded.has(searchId)) {
    newExpanded.delete(searchId);
  } else {
    newExpanded.add(searchId);
  }
  setExpandedSearches(newExpanded);
};
```

#### Filter Display Logic:
```javascript
const filterDisplayMap = {
  star: 'Star Rating',
  dateFrom: 'From Date', 
  dateTo: 'To Date',
  camera: 'Camera',
  lens: 'Lens',
  isoRange: 'ISO Range',
  apertureRange: 'Aperture Range',
  fileExtension: 'File Type',
  hasComment: 'Has Comment'
};

const formatFilterValue = (key, value) => {
  if (key.includes('date')) return new Date(value).toLocaleDateString();
  if (key === 'star') return '⭐'.repeat(value);
  if (key === 'hasComment') return value ? 'Yes' : 'No';
  if (key.includes('Range')) return `${value.min || ''} - ${value.max || ''}`;
  return value;
};
```

#### Accessibility Considerations:
- Add ARIA attributes for collapsible panels
- Keyboard navigation support (Enter/Space to toggle)
- Screen reader announcements for expanded/collapsed state
```jsx
<button
  className="toggle-conditions"
  onClick={() => toggleExpanded(search.id)}
  aria-expanded={isExpanded}
  aria-controls={`conditions-${search.id}`}
  onKeyDown={(e) => {
    if (e.key === 'Enter' || e.key === ' ') {
      e.preventDefault();
      toggleExpanded(search.id);
    }
  }}
>
  {isExpanded ? '▽' : '▷'} Search Conditions
</button>
```

#### Edge Cases to Handle:
- Hide toggle arrow when no filters exist (only query)
- Show appropriate message when no conditions are set
- Handle undefined/null filter values gracefully
- Mobile responsive table layout (stack on small screens)
