# provide easy edit

## Editor

Add editor menu to Directory.jsx. Left of Maintenance.

Editor can change image style using CSS.
For example:

- cropping 
- rotation
- brightness 
- contrust
- etc. 

Allow CSS level edit and record the CSS style text to `photo_metadata`.
Editor menu has UI to control each CSS style.
And if parameter is changed, automatically effect the image currently showed in PhotoDisplay.jsx.

When finishing edit, allow user to choose `apply`, `save as copy` or `reset`.

1. When user chooses `reset` button, setting is cleared and showing image effect is reset.
2. When user chooses `apply`, record style setting to table and apply style when showing image.
3. When user chooses `save as copy`, save the style applied image as another image, 
   file name is original name without extention + sha256 of style text + original extention. 
   For example:
   - original.jpg to orignal-dsagdsak13dggadsegasd.jpg
   dsagdsak13dggadsegasd is dummy string like sha256 of `{transform: rotate(90deg)}`.
   Style key should be sorted alphabetically.
