# インポート処理の改良

現在、import時に、選択されたディレクトリ以下のファイルを個別に選択してインポート先の
ディレクトリにインポートしています。

問題点として、以下のものがあります。

-  別のSDカードからインポートする際に、同じ名前のファイルが存在するかもしれない

これを解決するために、以下の方針を考えています。

1. インポート元のディレクトリの親のディレクトリに、.photoclove-uuid というファイルがあるかチェック
2. 1 のファイルがなければ作成し、ファイル内に、生成したUUIDを記録する
3. インポートする際に、インポート先のディレクトリ(yyyy-mm-ddの日付のデェレクトリ)の下に、.photoclove-uuid 内のUUIDのフォルダを作成し、その中にインポートを行う
   example: 2025-01-01/123e4567-e89b-12d3-a456-426655440000/ 以下にファイルをインポートする

インポートしたファイルを表示する場合は、日付のディレクトリ直下のファイル及び、UUIDのディレクトリの下のファイルを同じ日付の下のものにあるものとして、フラットに表示する。
つまり、表示の仕方としては、現在の表示方法とは特に変わることはない。
