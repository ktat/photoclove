# Refactor State Management with React Context and Hooks

## Problem
The application currently suffers from props drilling and scattered state management:
- App.jsx has become a massive component with 40+ state variables
- Props are passed down through multiple component levels
- State updates are scattered across many components
- No clear separation between local and global state
- Difficult to track state changes and debug

## Current State Issues (from App.jsx analysis)
```jsx
// 40+ useState calls in App.jsx:

const [name, setName] = useState("");

const [showPhotosList, setShowPhotosList] = useState(true);

```

**Problems:**
- Props drilling (passing props through 3+ component levels)
- Tight coupling between components
- Difficult to test individual components
- Performance issues from unnecessary re-renders
- Complex state update logic scattered across components

## Proposed Solution

### 2. Implement Photo Management Context
Extract all photo-related state into a dedicated context.

**Files to create:**
- `src/context/PhotoContext.jsx`

```jsx
const PhotoContext = createContext();

export const PhotoProvider = ({ children }) => {
  const [photos, setPhotos] = useState({ photos: [] });
  const [currentDate, setCurrentDate] = useState("");
  const [currentPhotoPath, setCurrentPhotoPath] = useState("");
  const [currentPhotoIndex, setCurrentPhotoIndex] = useState(0);
  const [showPhotoDisplay, setShowPhotoDisplay] = useState(false);
  const [sortOfPhotos, setSortOfPhotos] = useState(0);
  const [starFilter, setStarFilter] = useState(0);
  const [hasCommentFilter, setHasCommentFilter] = useState(false);
  const [extensionFilter, setExtensionFilter] = useState("all");

  const photoActions = {
    displayPhoto: (path, index) => {
      setCurrentPhotoPath(path);
      setCurrentPhotoIndex(index);
      setShowPhotoDisplay(true);
    },
    closePhotoDisplay: () => {
      setShowPhotoDisplay(false);
      setCurrentPhotoPath("");
    },
    updateFilters: (filters) => {
      setSortOfPhotos(filters.sort || sortOfPhotos);
      setStarFilter(filters.star || starFilter);
      setHasCommentFilter(filters.hasComment ?? hasCommentFilter);
      setExtensionFilter(filters.extension || extensionFilter);
    }
  };

  return (
    <PhotoContext.Provider value={{
      // State
      photos, currentDate, currentPhotoPath, currentPhotoIndex,
      showPhotoDisplay, sortOfPhotos, starFilter, hasCommentFilter, extensionFilter,
      // Actions
      setPhotos, setCurrentDate, ...photoActions
    }}>
      {children}
    </PhotoContext.Provider>
  );
};

export const usePhoto = () => {
  const context = useContext(PhotoContext);
  if (!context) {
    throw new Error('usePhoto must be used within PhotoProvider');
  }
  return context;
};
```

### 3. Create Custom Hooks for Complex Logic
Extract complex state logic into reusable custom hooks.

**Files to create:**

- `src/hooks/useImportState.js`

```jsx
// src/hooks/usePhotoNavigation.js
export const usePhotoNavigation = () => {
  const { photos, currentPhotoIndex, setCurrentPhotoIndex, setCurrentPhotoPath } = usePhoto();
  
  const nextPhoto = useCallback(() => {
    if (currentPhotoIndex < photos.photos.length - 1) {
      const newIndex = currentPhotoIndex + 1;
      setCurrentPhotoIndex(newIndex);
      setCurrentPhotoPath(photos.photos[newIndex].file.path);
    }
  }, [currentPhotoIndex, photos, setCurrentPhotoIndex, setCurrentPhotoPath]);

  const prevPhoto = useCallback(() => {
    if (currentPhotoIndex > 0) {
      const newIndex = currentPhotoIndex - 1;
      setCurrentPhotoIndex(newIndex);
      setCurrentPhotoPath(photos.photos[newIndex].file.path);
    }
  }, [currentPhotoIndex, setCurrentPhotoIndex, setCurrentPhotoPath]);

  return { nextPhoto, prevPhoto, hasNext: currentPhotoIndex < photos.photos.length - 1, hasPrev: currentPhotoIndex > 0 };
};
```

### 4. Implement UI State Management
Create a dedicated context for UI state (modals, panels, loading states).

**Files to create:**
- `src/context/UIContext.jsx`

```jsx
const UIContext = createContext();

export const UIProvider = ({ children }) => {
  const [showImporter, setShowImporter] = useState(false);
  const [showPreferences, setShowPreferences] = useState(false);
  const [showJobQueue, setShowJobQueue] = useState(false);
  const [showSideMenu, setShowSideMenu] = useState(false);
  const [footerMessages, setFooterMessages] = useState({});
  const [hideLoading, setHideLoading] = useState(false);

  const uiActions = {
    toggleImporter: (show) => {
      setShowImporter(show);
      if (show) {
        setShowPreferences(false);
        setShowJobQueue(false);
      }
    },
    togglePreferences: (show) => {
      setShowPreferences(show);
      if (show) {
        setShowImporter(false);
        setShowJobQueue(false);
      }
    },
    addFooterMessage: (key, message, withDialog, deleteAfter) => {
      setFooterMessages(prev => ({ ...prev, [key]: message }));
      if (deleteAfter) {
        setTimeout(() => {
          setFooterMessages(prev => {
            const newMessages = { ...prev };
            delete newMessages[key];
            return newMessages;
          });
        }, deleteAfter);
      }
    }
  };

  return (
    <UIContext.Provider value={{
      // State
      showImporter, showPreferences, showJobQueue, showSideMenu,
      footerMessages, hideLoading,
      // Actions
      ...uiActions, setShowSideMenu, setHideLoading
    }}>
      {children}
    </UIContext.Provider>
  );
};
```
