# Improvement 42: Fix Search Feature UI and Backend Alignment

## Problems Identified

### 1. Advanced Filters UI vs Backend Mismatch
The Advanced Filters UI provides extensive filter options that are not implemented in the backend:

**Frontend offers:**
- Camera Equipment (Camera, Lens dropdowns)
- Technical Settings (ISO range, Aperture range, Focal length range)
- Date Range (Start/End date pickers)
- Star Rating filter
- File Extension filter
- Has Comments checkbox

**Backend only implements:**
- Basic text search in filename, comment, camera make/model, lens model
- No advanced filtering functionality

### 2. Search Types Mismatch
SearchBar component offers search types that are not implemented in backend:

**Frontend offers:**
- "all", "filename", "comment", "camera", "settings", "date", "exif"

**Backend only implements:**
- "all", "filename", "comment", "camera"
- Missing: "settings", "date", "exif" search types

### 3. Hardcoded Filter Options
Backend returns hardcoded camera/lens data instead of reading from database:
```rust
let cameras = vec![
    CameraInfo {
        id: "canon_5d".to_string(),
        make: "Canon".to_string(),
        model: "EOS 5D Mark IV".to_string(),
        count: 150,
    },
    // ... hardcoded data
];
```

### 4. Missing Search Result Metadata
Search results don't include all metadata that the UI expects:
- Advanced filter parameters are not applied
- Search relevance scoring is hardcoded to 1.0
- EXIF data filtering is not implemented

## Proposed Solutions

### Phase 1: Backend Search Enhancement
1. **Implement missing search types:**
   - "settings" - Search in camera settings (ISO, aperture, focal length)
   - "date" - Search in date fields
   - "exif" - Search in all EXIF data fields

2. **Add advanced filter support:**
   - Camera/lens filtering by database values
   - ISO range filtering
   - Aperture range filtering
   - Focal length range filtering
   - Date range filtering
   - Star rating filtering
   - File extension filtering

3. **Dynamic filter options:**
   - Read actual camera/lens data from database
   - Return real counts and available options
   - Cache filter options for performance

### Phase 2: Search Query Enhancement
1. **Improve search SQL:**
   ```sql
   -- Current simple search
   SELECT * FROM photo_metadata WHERE path LIKE '%query%'
   
   -- Enhanced with filters
   SELECT * FROM photo_metadata 
   WHERE (search_conditions) 
   AND (iso_value BETWEEN ? AND ?)
   AND (aperture_value BETWEEN ? AND ?)
   AND (date_taken BETWEEN ? AND ?)
   AND (star >= ?)
   ORDER BY relevance_score DESC
   ```

2. **Add search relevance scoring:**
   - Exact matches score higher
   - Multiple field matches score higher
   - Recent photos score higher

### Phase 3: UI Improvements
1. **Search result indicators:**
   - Show which fields matched
   - Highlight search terms in results
   - Show applied filters clearly

2. **Search performance:**
   - Add search debouncing
   - Show loading states
   - Cache frequent searches

### Phase 4: Search Analytics
1. **Search history:**
   - Track search patterns
   - Popular searches
   - Search result quality metrics

2. **Search suggestions:**
   - Auto-complete for common searches
   - Suggested filters based on results
