# Implement Advanced Search and Metadata Filtering

## Problem
The current search and filtering capabilities are limited:
- No text-based search functionality
- EXIF data is stored but not searchable from UI
- Limited filtering options (only star, comment, extension)
- No combined filter queries
- No search history or saved searches
- Missing camera/equipment-based filtering

## Current State Analysis
From the codebase analysis:
- EXIF data is extracted and stored in SQLite database
- Basic filters exist: star rating, has comment, file extension
- No text search UI in any component
- Rich EXIF metadata available but not exposed for filtering
- DirectoryMenu.jsx only shows basic filter controls

## Proposed Solution

### 3. Implement Backend Search Support
Add Tauri commands for advanced search and filtering.

- `src-tauri/src/lib.rs`

```rust
#[tauri::command]
async fn search_photos(
    query: &str,
    search_type: &str,
    filters: SearchFilters,
    state: tauri::State<'_, AppState>,
) -> Result<String, String> {
    let meta_db = &state.meta_db;
    
    let search_results = match search_type {
        "filename" => meta_db.search_by_filename(query),
        "comment" => meta_db.search_by_comment(query),
        "camera" => meta_db.search_by_camera(query),
        "settings" => meta_db.search_by_settings(query, &filters),
        "all" => meta_db.search_all_fields(query),
        _ => meta_db.search_all_fields(query),
    }?;
    
    Ok(serde_json::to_string(&search_results).unwrap())
}

#[tauri::command]
async fn get_filter_options(
    filter_type: &str,
    state: tauri::State<'_, AppState>,
) -> Result<String, String> {
    let meta_db = &state.meta_db;
    
    let options = match filter_type {
        "cameras" => meta_db.get_unique_cameras(),
        "lenses" => meta_db.get_unique_lenses(),
        "iso_values" => meta_db.get_iso_range(),
        "aperture_values" => meta_db.get_aperture_range(),
        _ => Vec::new(),
    }?;
    
    Ok(serde_json::to_string(&options).unwrap())
}
```
