# Improvement of Tags

## Tags List View

Like Albums List view, implement Tags List View.
PhotosList should be used for Tags List and cover photo is last tagged photo.
PhotosList should also be used for photos in a Tag.
PhotosListMini shoud be used for showing a Photo in the list of photos in a Tag.

The icon to access list of tags should be placed next to album icon in the top of left column.

## Tags Management

No need to tag management feature in Preferences.

Tags
