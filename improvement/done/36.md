# Add Comprehensive Unit and Integration Testing

## Problem
The codebase currently lacks proper testing infrastructure:
- No unit tests for React components
- No integration tests for Tauri commands
- No automated testing in CI/CD pipeline
- Difficult to ensure quality and prevent regressions
- Manual testing is time-consuming and error-prone

## Current Testing State
From codebase analysis:
- `src-tauri/tests/` directory exists but appears minimal
- No Jest or Vitest configuration for frontend testing
- No test files found in React components
- No automated testing in build process
- No test coverage reporting

## Proposed Solution

### 1. Setup Frontend Testing Infrastructure
Establish comprehensive testing for React components and utilities.

**Testing Stack:**
- **Vitest**: Fast unit testing (better Vite integration than Jest)
- **React Testing Library**: Component testing
- **MSW**: Mock Service Worker for API mocking
- **@testing-library/user-event**: User interaction testing

**Files to create:**
- `vitest.config.js`
- `src/test/setup.js`
- `src/test/mocks/tauriMocks.js`

```js
// vitest.config.js
import { defineConfig } from 'vitest/config';
import { mergeConfig } from 'vite';
import viteConfig from './vite.config.js';

export default mergeConfig(viteConfig, defineConfig({
  test: {
    globals: true,
    environment: 'jsdom',
    setupFiles: ['src/test/setup.js'],
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      exclude: [
        'node_modules/',
        'src/test/',
        '**/*.config.js',
        '**/*.config.ts',
      ],
    },
  },
}));
```

import { render } from '@testing-library/react';
import { PhotoProvider } from '../context/PhotoContext';
import { UIProvider } from '../context/UIContext';

export const renderWithProviders = (ui, options = {}) => {
  const { initialState = {}, ...renderOptions } = options;

  const Wrapper = ({ children }) => (
    <PhotoProvider initialState={initialState.photo}>
      <UIProvider initialState={initialState.ui}>
        {children}
      </UIProvider>
    </PhotoProvider>
  );

  return render(ui, { wrapper: Wrapper, ...renderOptions });
};

export const createMockInvoke = (responses = {}) => {
  return vi.fn((command, args) => {
    const response = responses[command];
    if (typeof response === 'function') {
      return Promise.resolve(response(args));
    }
    return Promise.resolve(response || '{}');
  });
};

import { test, expect } from '@playwright/test';

test.describe('Photo Import', () => {
  test('should import photos successfully', async ({ page }) => {
    await page.goto('/');
    
    // Navigate to import
    await page.click('text=import');
    
    // Select photos and import
    await page.selectOption('[name="directory"]', '/test/photos');
    await page.click('[data-testid="select-all"]');
    await page.click('[data-testid="import-selected"]');
    
    // Verify import progress
    await expect(page.locator('[data-testid="import-progress"]')).toBeVisible();
    
    // Wait for completion
    await expect(page.locator('text=Import completed')).toBeVisible({ timeout: 30000 });
  });
});

### 6. Setup CI/CD Testing Pipeline
Integrate testing into the build process.

**Files to create:**
- `.github/workflows/test.yml`

```yaml
# .github/workflows/test.yml
name: Tests

on: [push, pull_request]

jobs:
  frontend-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '18'
          cache: 'pnpm'
      
      - run: pnpm install
      - run: pnpm test:unit
      - run: pnpm test:coverage
      
      - name: Upload coverage
        uses: codecov/codecov-action@v3
        with:
          file: ./coverage/lcov.info

  backend-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions-rs/toolchain@v1
        with:
          toolchain: stable
      
      - name: Run tests
        run: cd src-tauri && cargo test

  e2e-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '18'
          cache: 'pnpm'
      
      - run: pnpm install
      - run: pnpm playwright install
      - run: pnpm test:e2e
```
