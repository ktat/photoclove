# Editor: Crop機能の修正

## Overview

Crop（トリミング）機能が保存時に反映されない問題を修正する。

## 問題一覧

| 優先度 | ファイル | 行 | 問題 |
|--------|----------|-----|------|
| 🔴 | photoExportUtils.js | 26 | cropがdestructureされていない |
| 🔴 | photoExportUtils.js | 69-70 | cropが渡されていない |
| 🔴 | imageProcessing.js | 180-181 | cropパラメータがない |
| 🔴 | imageProcessing.js | 196 | Crop処理が未実装 |
| 🟠 | cropUtils.js | 100-101 | 境界チェックが複雑 |

## 問題詳細

### 🔴 問題1: Save処理でCropが無視される

**ファイル**: `photoExportUtils.js:26`

```javascript
// cropが含まれていない
const { rotate, brightness, contrast, saturation, hue, scale } = editorStyles;
```

### 🔴 問題2: Canvas変換処理にCropが未実装

**ファイル**: `imageProcessing.js:180-196`

```javascript
export function applyTransformsToCanvas(ctx, canvasWidth, canvasHeight, sourceCanvas, transforms) {
```

### 🔴 問題3: 呼び出し時にcropが渡されていない

**ファイル**: `photoExportUtils.js:69-70`

```javascript
applyTransformsToCanvas(ctx, canvas.width, canvas.height, tempCanvas,
    { rotate, scale });  // ← cropが渡されていない
```

### 🟠 問題4: 境界チェックロジックの欠陥

**ファイル**: `cropUtils.js:100-101`

```javascript

height: Math.max(0, Math.min(height, 100 - Math.max(0, startY)))
```

ロジックが複雑で、画像外へのドラッグ時に予期しない結果になる可能性。

## 修正方針

### 新関数: applyCropToCanvas

```javascript
export function applyCropToCanvas(sourceCanvas, crop) {
    if (!crop || isCropDefault(crop)) {
        return sourceCanvas;
    }

    const cropX = (crop.x / 100) * sourceCanvas.width;
    const cropY = (crop.y / 100) * sourceCanvas.height;
    const cropWidth = (crop.width / 100) * sourceCanvas.width;
    const cropHeight = (crop.height / 100) * sourceCanvas.height;

    const croppedCanvas = document.createElement('canvas');
    croppedCanvas.width = cropWidth;
    croppedCanvas.height = cropHeight;
    const ctx = croppedCanvas.getContext('2d');

    ctx.drawImage(sourceCanvas, cropX, cropY, cropWidth, cropHeight, 0, 0, cropWidth, cropHeight);

    return croppedCanvas;
}
```

### 修正箇所

1. `photoExportUtils.js:26`: cropをdestructureに追加
2. `photoExportUtils.js:69-70`: cropを渡す
3. `imageProcessing.js`: `applyCropToCanvas()`を追加
4. `cropUtils.js`: 境界チェック簡素化
