## 推奨実装順序

1. **165-1-crop.md** - Crop機能（最も影響大）
2. **165-2-rotate-scale.md** - 寸法計算（Cropと関連）
3. **165-3-filters.md** - フィルター処理
4. **165-4-exif-format.md** - Exif保存
5. **165-5-css-backend.md** - CSS解析改善

## 修正後の処理フロー

```
1. 元画像をCanvasに描画
2. フィルター適用 (brightness, contrast, saturation, hue)
3. Crop適用 → 新Canvas作成（Crop後サイズ）
4. 回転適用 → 必要なら縦横入れ替え
5. Scale適用 → 出力Canvas作成（Scale後サイズ）
6. Exif情報を元画像からコピー
7. 最終画像を出力
```
