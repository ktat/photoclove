# add new page to manage job queue

Create new page to manage job queue.
the page can be accessed from the above of the `Preferences` in `File` menu.

- List job queue in table. show the following:
  - job type
  - number of job target
  - job status
  - the reason why job failed if status is failed
  - the time: created,started,finished
- allow some operations for job
  - retry job for failed status jobs
  - delete job when status is failed or pending.
    - don't allow delete job when job is started on the delete operation.
    - so you should add where condition like `status = 'pending'`
  - stop job when status is running.
    - user operate stopping job and create file to indicate stopping specific job
    - while job execution, check the file and stop job if the file exists
- reload job list after job operation
