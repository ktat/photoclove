# フィルターオプションキャッシュ機能実装

## 概要

improvement #44で未実装だったフィルターオプションのキャッシュ機能を実装し、Advanced Search Options表示時のパフォーマンスを大幅改善する。

## 🚨 緊急度：高（パフォーマンス問題）

### 現状の問題

**パフォーマンス問題**:
- `src/components/AdvancedFilters.jsx:27-51` - 毎回`get_filter_options`コマンドでDB読み取り
- Advanced Search Options表示の度に不要なDB負荷発生
- ユーザー体感として遅延が発生（2-3秒）

**実装設計**:
SearchPageレベルでfilterOptionsをキャッシュし、props経由で子コンポーネントに渡す。

## 実装対象ファイル

- `src/App/PhotosList.jsx` - SearchPageレベルでfilterOptionsキャッシュstate追加
- `src/components/SearchTools.jsx` - キャッシュされたfilterOptionsをprops経由で受け取り
- `src/components/AdvancedFilters.jsx` - propsのfilterOptionsを使用、直接DB呼び出し削除

## 具体的実装変更

### A. `src/App/PhotosList.jsx` - キャッシュstate追加

```javascript
// 新規state追加（行番号推定: ~90）
const [filterOptions, setFilterOptions] = useState(null);
const [isFilterOptionsLoading, setIsFilterOptionsLoading] = useState(false);

// キャッシュロード関数追加
const loadFilterOptions = useCallback(async () => {
    if (filterOptions || isFilterOptionsLoading) return filterOptions;
    
    setIsFilterOptionsLoading(true);
    try {
        const options = await invoke('get_search_filter_options');
        setFilterOptions(JSON.parse(options));
        return JSON.parse(options);
    } catch (error) {
        console.error('Failed to load filter options:', error);
        return null;
    } finally {
        setIsFilterOptionsLoading(false);
    }
}, [filterOptions, isFilterOptionsLoading]);

// SearchTools component に props 追加（行番号推定: ~1000）
<SearchTools
    // ... existing props
    filterOptions={filterOptions}
    onLoadFilterOptions={loadFilterOptions}
    isFilterOptionsLoading={isFilterOptionsLoading}
/>
```

### C. `src/components/AdvancedFilters.jsx` - 直接DB呼び出し削除

```javascript
// 既存のuseEffect削除（行27-51）
// 削除対象:
// useEffect(() => {
//   const loadFilterOptions = async () => { ... }
// }, []);

// 新規実装: props経由でfilterOptions使用
function AdvancedFilters({ 
    // ... existing props
    filterOptions, 
    onLoadFilterOptions, 
    isLoading 
}) {
    // コンポーネントマウント時にキャッシュロード要求
    useEffect(() => {
        if (!filterOptions && !isLoading) {
            onLoadFilterOptions();
        }
    }, [filterOptions, onLoadFilterOptions, isLoading]);

    // filterOptions が null の場合はローディング表示
    if (!filterOptions && isLoading) {
        return <div>Loading filter options...</div>;
    }
    
    // 既存のfilterOptions使用ロジックはそのまま維持
}
```
