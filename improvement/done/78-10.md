# Update UI title display to use viewModeObj.getModeTitle()

## Task Description
Replace all UI title displays that currently use `fetchConfig?.title` with `viewModeObj.getModeTitle()` calls.

## Implementation Details

### Current Code Pattern
```javascript
// In UI components
<span>{fetchConfig?.title || 'Photos'}</span>
<h1>{fetchConfig?.title}</h1>
{fetchConfig && <Title>{fetchConfig.title}</Title>}
```

### New Code Pattern
```javascript
// After update
<span>{viewModeObj.getModeTitle()}</span>
<h1>{viewModeObj.getModeTitle()}</h1>
<Title>{viewModeObj.getModeTitle()}</Title>
```

## Files to Search and Modify
Search for these patterns across the codebase:
- `fetchConfig?.title`

- `fetchConfig && fetchConfig.title`

Common locations:
- `src/App/PhotosList.jsx`
