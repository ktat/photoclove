# 検索履歴の拡張データ構造実装

## 概要

improvement #44で設計されたが未実装だった検索履歴の拡張データ構造を実装し、フィルター情報・ソート設定を含む詳細な検索履歴機能を提供する。

## 🔧 緊急度：中（機能改善）

### 現状の問題

**機能制限**:
- `src/hooks/useSearch.js:saveSearchHistory` - 単純な文字列配列のみ保存
- フィルター情報、ソート設定が履歴に含まれない
- 複雑な検索条件の再現ができない
- 検索結果件数や実行日時の情報がない

**設計方針**:
検索履歴データ構造をオブジェクト形式に拡張し、検索の完全な再現と詳細情報の保存を実現する。

## 実装対象ファイル

- `src/hooks/useSearch.js` - 履歴データ構造とUI改善
- `src/components/SearchTools.jsx` - 履歴表示UI改善（将来の拡張準備）

## 具体的実装変更

### A. `src/hooks/useSearch.js` - 拡張履歴データ構造

```javascript
// saveSearchHistory関数の更新（行32-43周辺）
const saveSearchHistory = useCallback((query, type, filters = {}, sortField = null, sortOrder = null, resultCount = 0) => {
    if (!query.trim()) return;
    
    const historyEntry = {
        query: query.trim(),
        type,
        filters: { ...filters }, // deep copy
        sortField: sortField || 'exif_date_time_original',
        sortOrder: sortOrder || 'desc',
        resultCount,
        timestamp: new Date().toISOString()
    };
    
    setSearchHistory(prev => {
        // 重複エントリ削除（同じquery + filters の組み合わせ）
        const filtered = prev.filter(item => {
            // 旧形式（文字列）との互換性維持
            if (typeof item === 'string') {
                return item !== query.trim();
            }
            // 新形式（オブジェクト）での重複チェック
            return !(item.query === query.trim() && 
                     JSON.stringify(item.filters) === JSON.stringify(filters) &&
                     item.sortField === sortField &&
                     item.sortOrder === sortOrder);
        });
        
        const newHistory = [historyEntry, ...filtered].slice(0, 10); // 最大10件
        localStorage.setItem('photo_search_history', JSON.stringify(newHistory));
        return newHistory;
    });
}, []);

// performSearch関数での履歴保存更新（行138周辺）
// 既存の saveSearchHistory(query, type, searchData.length); を以下に変更
saveSearchHistory(query, type, filters, sortField, sortOrder, searchData.length);
```

### B. 履歴読み込み時の互換性処理

```javascript
// useSearch hook の初期化処理更新
useEffect(() => {
    const stored = localStorage.getItem('photo_search_history');
    if (stored) {
        try {
            const parsed = JSON.parse(stored);
            // 旧形式（文字列配列）から新形式（オブジェクト配列）への変換
            const converted = parsed.map(item => {
                if (typeof item === 'string') {
                    // 旧形式を新形式に変換
                    return {
                        query: item,
                        type: 'all',
                        filters: {},
                        sortField: 'exif_date_time_original',
                        sortOrder: 'desc',
                        resultCount: 0,
                        timestamp: new Date().toISOString()
                    };
                }
                // 新形式はそのまま
                return item;
            });
            setSearchHistory(converted);
            
            // 変換後の形式で保存し直す
            if (converted.some((item, index) => typeof parsed[index] === 'string')) {
                localStorage.setItem('photo_search_history', JSON.stringify(converted));
            }
        } catch (error) {
            console.error('Failed to parse search history:', error);
            setSearchHistory([]);
        }
    }
}, []);
```

### C. 履歴エントリからの検索再現機能

```javascript
// 履歴エントリから検索を再現する関数
const replaySearchFromHistory = useCallback((historyEntry) => {
    if (typeof historyEntry === 'string') {
        // 旧形式の場合は基本的な検索のみ実行
        performSearch(historyEntry, 'all', {});
    } else {
        // 新形式の場合は完全な検索再現
        performSearch(
            historyEntry.query,
            historyEntry.type,
            historyEntry.filters,
            historyEntry.sortField,
            historyEntry.sortOrder
        );
    }
}, [performSearch]);

// useSearch hook の return に追加
return {
    // ... existing returns
    replaySearchFromHistory,
    searchHistory,
    // ... other returns
};
```

### D. 履歴表示用のヘルパー関数

```javascript
// 履歴エントリを表示用文字列に変換する関数
const formatHistoryEntry = useCallback((entry) => {
    if (typeof entry === 'string') {
        return {
            display: entry,
            subtitle: 'Legacy search',
            timestamp: null
        };
    }
    
    // フィルター概要の生成
    const filterSummary = [];
    if (entry.filters.camera) filterSummary.push(`Camera: ${entry.filters.camera}`);
    if (entry.filters.lens) filterSummary.push(`Lens: ${entry.filters.lens}`);
    if (entry.filters.star_rating > 0) filterSummary.push(`${entry.filters.star_rating}+ stars`);
    if (entry.filters.date_range?.start) filterSummary.push(`Date range`);
    
    const subtitle = [
        filterSummary.length > 0 ? filterSummary.slice(0, 2).join(', ') : 'No filters',
        `${entry.resultCount} results`,
        `Sort: ${entry.sortField} ${entry.sortOrder}`
    ].join(' • ');
    
    return {
        display: entry.query,
        subtitle,
        timestamp: entry.timestamp ? new Date(entry.timestamp).toLocaleDateString() : null
    };
}, []);
```
